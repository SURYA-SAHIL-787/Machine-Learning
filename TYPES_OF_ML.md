# TYPES OF MACHINE LEARNING

# ============================================================

Machine Learning can be broadly classified into three main types
based on how models learn from data.

---

1. SUPERVISED LEARNING

---

Definition:
Supervised Learning is a type of ML where the model is trained
on labeled data (input + correct output).

Goal:
Learn a mapping from input → output.

Examples:

* Email Spam Detection
* House Price Prediction
* Student Score Prediction

Types:

* Regression (continuous output)
* Classification (categorical output)

Key Idea:
Model learns from "known answers".

---

2. UNSUPERVISED LEARNING

---

Definition:
Unsupervised Learning deals with unlabeled data where the model
tries to find hidden patterns or structures.

Goal:
Discover patterns without predefined labels.

Examples:

* Customer Segmentation
* Market Basket Analysis
* Grouping similar news articles

Types:

* Clustering (K-Means)
* Association (Apriori)

Key Idea:
Model learns patterns on its own.

---

3. REINFORCEMENT LEARNING

---

Definition:
Reinforcement Learning is based on learning through interaction
with an environment using rewards and penalties.

Goal:
Maximize total reward over time.

Examples:

* Game Playing (Chess, PUBG bots)
* Self-driving cars
* Robotics

Key Components:

* Agent
* Environment
* Reward
* Action

Key Idea:
Learning by trial and error.

---

## SUMMARY TABLE

| Type          | Data Type   | Goal            |
| ------------- | ----------- | --------------- |
| Supervised    | Labeled     | Predict output  |
| Unsupervised  | Unlabeled   | Find patterns   |
| Reinforcement | Interaction | Maximize reward |
